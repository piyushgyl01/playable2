# playable

a save file for your actual life.

not a productivity app with game paint on it. a persistent character generated by
things you actually did.

    REAL ACTION → RECORDED EVENT → RULE → PERSISTENT STATE

## the engine is the product

every number is a fold over an event log. the same events always produce the same
state, and every number can name the rule that moved it — open **the ledger** and
each line shows its rule and arithmetic. no model runs at any point. nothing is
generated. the state would survive being recomputed from scratch.

## the numbers are honest

health xp does not claim you are healthy. it claims:

    evidence you invested in your body

same for the others. that precision is what makes it worth trusting instead of
another badge system.

## the day declares its own difficulty

    full      everything on the board
    normal    a real day
    low       not much left in the tank
    recovery  resting is the quest

this changes what **clearing the day** means, never what anything is worth. so a
bad day is still winnable, and the streak counts days you hit the bar *you set* —
not days you were perfect. on recovery days rest is a completable action worth
health xp, because rest is play, not the absence of it.

this is the fix for the thing that actually broke: 14 dailies and a best-ever day
of 8 meant every single day ended in failure.

## effort counts

a completion can be logged as **min** (0.5×), normal (1×) or **hard** (2×). the
two-minute version still counts. the version that cost you something counts more.
normal is 1.0, so a save that never logs effort produces numbers identical to v1.

## it reads your state back to you

    The Builder · player lvl 17
    wealth-dominant, relationships-starved

    day cleared — 5 of 14, you needed 5.
    wealth is carrying this run — 80% of everything you have done.
    relationships has been under 15% for 20 days.
    this week 17, last week 40 — slowing.
    1 more completion to player lvl 18.

## chapters

each week seals into a short recap — what you did, which pillar led, how many days
you cleared, how many you rested. progress as story, not only numbers.

## arcs

a chapter you are trying to live, not a task. steps, no deadline, no penalty.

## rewards

xp is spendable on things you define. lifetime never drops; spent is tracked
separately. this is what the number is *for*.

## data

`tasks.json` keeps v1's exact shape and is the event source — the `todo` CLI and
the four GitHub Actions keep working against it, untouched. everything this
version adds lives in `state.json`, which they never read.

no punishment for missed days. no manufactured streak anxiety. rest is legitimate.
difficulty bends to the human. the app shows you what kind of life you are
currently playing — it does not nag you toward a better one.
